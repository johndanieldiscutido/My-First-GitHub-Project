# My Favorite Movie

## Movie Title: Inside Out 2

**Genre:** Animation / Comedy / Adventure

**Description:**

Inside Out 2 is an animated movie that follows Riley as she experiences new emotions while growing up. The story introduces new emotions, including Anxiety, Envy, Embarrassment, and Ennui, as Riley faces the challenges of being a teenager.

**Why I Like It:**

I like Inside Out 2 because it teaches important lessons about understanding emotions, accepting yourself, and dealing with changes in life. It is entertaining, relatable, and meaningful for people of different ages.
